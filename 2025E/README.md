# Refactor Workspace

This directory is used to reorganize NUEDC 2025 project assets on branch `develop`.

## Structure
- `Project/`: CCS-importable source project(s)
- `Report/`: competition report assets
- `Reference/`: reusable examples and references
- `LOGS/`: operation and commit logs for audit

## CCS Import Entry
- Recommended: import from `refactor/Project/NUEDC2025_MSPM0_CCS` as an existing CCS Eclipse project.
- Optional: import from `refactor/Project/NUEDC2025_MSPM0_CCS/ticlang` via `.projectspec`.
